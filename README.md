# REDasm File Format Loaders
This repository contains the official, hot-pluggable file format loaders for the **[REDasm Core Engine](https://github.com/redasm-dev/core)**.

## Supported Formats
*   **Retro & Consoles**: Nintendo NES (NROM), Sony PlayStation 1 (EXE/BIOS), original Xbox (XBE), ZX Spectrum.
*   **Mainstream OS**: MS-DOS (MZ), Windows 16-bit (NE), Windows 32/64-bit (PE), Linux/Unix (ELF/ELF64), OS/2 (LE/LX).
*   **Mobile**: Dalvik executable (DEX).
